## 2. Appris
- L'ESP32-S3 ne convient pas pour ce test à cause d'un nombre de broches trop limité
- Le capteur infrarouge du suiveur de ligne réagit différemment selon la couleur du support : sur fond blanc, il déclenche une réaction (rotation des roues) même à bonne distance ; sur fond noir, il faut rapprocher le capteur beaucoup plus près pour obtenir la même réaction
- Un seul exemplaire du suiveur de ligne était disponible sur les deux commandés, ce qui limite les possibilités de test et de comparaison

## 3. Raté puis corrigé
- **Raté** : le suiveur de ligne ne respectait pas les exigences attendues, malgré plusieurs tentatives (support blanc/noir, réglage de sensibilité)
- **Non corrigé à ce jour** : aucune des pistes testées n'a résolu le problème ; la session s'est terminée sans conclusion sur ce point — la correction est reportée au lendemain avec du nouveau matériel

## 4. Décidé
- Abandon temporaire de l'Arduino Nano pour la suite : les consignes du projet interdisant l'usage d'Arduino, les tests du jour n'avaient qu'une valeur de vérification ponctuelle
- Le formateur fournira une nouvelle carte ESP32 dès le lendemain pour reprendre les tests dans le respect des consignes
- Priorité fixée pour la prochaine séance : revalider en particulier le suiveur de ligne

## 5. À faire demain
- Reprendre les tests de chaque capteur indépendamment avec la nouvelle carte ESP32 fournie par le formateur
- Retester spécifiquement le suiveur de ligne pour tenter d'aboutir à une conclusion sur le problème rencontré
- Vérifier la conformité du composant reçu par rapport à celui commandé (TCRT5000)
